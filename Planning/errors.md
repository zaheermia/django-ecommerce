# What Could Go Wrong

## Website
- **Wrong login** - show an error
- **No permission** - show "not allowed"
- **Page doesn't exist** - 404 page
- **Empty cart at checkout** - send back to cart
- **Reset link expired** - tell them to get a new one

## API
- **Not logged in or wrong password** - 401
- **Not allowed** - 403
- **Missing or wrong data** - 400
- **Store doesn't exist** - 404

## Reddit
- **Reddit doesn't answer or sends an error** - show an error message on the page
